# requirements.txt — SEE requirements-spark.txt
# =============================================================================
# This project's dependencies are PLATFORM-SPECIFIC and pinned in a dedicated
# file, because the environment is NVIDIA DGX Spark / GB10 (aarch64, CUDA 13,
# sm_121) and TensorFlow-free by necessity.
#
#   ->  Use  requirements-spark.txt  together with  scripts/clean_install.sh
#
# Do NOT `pip install -r requirements.txt` expecting a working environment —
# the real, tested install path is:
#
#   cd ~/perch-hoplite
#   bash scripts/clean_install.sh          # pins torch (cu130), perch-hoplite
#                                          # ==1.0.2, usearch==2.25.3, etc.,
#                                          # verifies TF-free, checks sox binary
#
# Why not a plain requirements.txt: the torch cu130 wheels and the
# aarch64/sm121 ONNX wheel are GB10-specific and would fail elsewhere; and
# `sox` (Stage 1 resampling) is a SYSTEM package (apt), not pip. See
# docs/perch_hoplite_tf_free_setup.md for the TF-free rationale.
#
# Cross-platform install paths (Mac / Colab / AWS) are a documented TODO in
# scripts/clean_install.sh — not yet written or tested.
# =============================================================================
